## 📦 Installation

1. Download the plugin archive (`premium-auto-content.zip`).
2. Log in to your WordPress admin dashboard.
3. Navigate to **Plugins > Add New > Upload Plugin**.
4. Select the downloaded ZIP file and click **Install Now**.
5. Click **Activate** to enable the plugin.
6. Navigate to **Auto Content AI > Settings** to configure your Google Gemini API key.

---

## ⚙️ Configuration

1. Get your API key from [Google AI Studio](https://makersuite.google.com/app/apikey).
2. Go to **WordPress Admin > Auto Content AI > Settings**.
3. Enter your **Gemini API Key** and select your preferred model (`Gemini 1.5 Pro` recommended for complex content, `Gemini 1.5 Flash` for speed).
4. Configure default content length, language, SEO settings, and auto-publishing options.
5. Click **Save Settings** and test the connection.

## 📖 Usage

### Admin Dashboard
Access the main control center at **Auto Content AI** in your WordPress sidebar to view statistics, recent generation logs, and quick actions.

### Content Generator
1. Go to **Auto Content AI > Generator**.
2. Enter your topic or prompt, select content type, length, language, and SEO keywords.
3. Click **Generate Content**.
4. Review the generated content, SEO analysis, and schema markup, then click **Create Post** or copy to clipboard.

### Content Templates
Create reusable prompt templates under **Auto Content AI > Templates** to streamline content creation for specific niches or categories.

### Automated Scheduler
Enable and configure the scheduler under **Auto Content AI > Scheduler** to automatically generate and publish content on your defined schedule.
